# Debugging

Debugging is a luxury, granted only to those originally registered developers who obtained an official XDK (and hence SDK). A few researchers have found that writing out logging files to disk seems to be just as useful.

Although this method would not allow a developer to view the call stack, peak at variables and their values nor step through breakpoints, it definitely can be used to provide insightful information.
